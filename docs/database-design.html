ER ระบบธุรกิจ

ข้อกำหนดความถูกต้อง

  • email และ std_id ไม่ซ้ำ; Backend สมัครบังคับ std_id ตัวเลข ASCII 13 หลัก ชื่อและนามสกุลต้องไม่ว่าง
  • status: confirmed/cancelled; ยกเลิกเก็บประวัติและคืนสิทธิ์
  • uniq_confirmed_court_slot: court + date + start_time ไม่ซ้ำเมื่อ confirmed
  • uniq_confirmed_user_day: user + date ไม่ซ้ำเมื่อ confirmed
  • เวลาจองครั้งละหนึ่งชั่วโมง เริ่ม 08:00–19:00 จองได้วันนี้ถึงอีก4วัน ห้ามช่วงที่ผ่านแล้ว
  • ลบ User/Court ด้วย Admin จะ CASCADE ลบ Appointment ที่สัมพันธ์ มีหน้าจอยืนยันและการทดสอบผลนี้ หากต้องรักษาประวัติระยะยาวควรออกแบบปิดใช้งานสนามแทนลบ

ตารางระบบ Django เพิ่มเติม
